This is a small fix for 0.9.0. Servers on 0.9.0 are offered it from the Settings page.

## Fixed

- An app whose install failed, or that was never installed, now shows an Install button again. Before, it showed "Needs attention" with only a Start button, and Start could not work because nothing was installed. This happened to Nextcloud on the first try after a failed install.
- The message from the failed attempt is still shown, so you can see what went wrong before you try again.

## Updating

Open Settings and choose Check for updates, then Update. Your apps stay on while the dashboard restarts. New installs get this version automatically.
