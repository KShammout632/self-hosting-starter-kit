This is the first pre-release of the self-hosting starter kit. It turns a fresh Ubuntu Server 24.04 machine into a home media and file server with Jellyfin, Navidrome, Immich and Nextcloud, run from a web dashboard.

It is a beta. It has passed the automated install, storage, update and remote access tests on fresh Ubuntu 24.04 machines, but it has not yet been tested on real mini PC hardware. Please try it on a machine that holds nothing you cannot lose, and report what goes wrong.

## Install

On a fresh Ubuntu Server 24.04 machine (x86-64, 4 GB of memory or more):

```bash
curl -fsSL https://raw.githubusercontent.com/imtinkering/self-hosting-starting-kit/main/install.sh -o install.sh
sudo bash install.sh
```

The installer downloads this release and checks its signature before installing anything. Then open the address it prints and follow the setup guide. The [user guide](https://github.com/imtinkering/self-hosting-starting-kit/blob/v0.9.0/docs/user-guide.md) explains each step.

## What is in it

- A setup guide that installs the apps you choose, one at a time.
- A Home page showing whether each app is running, with start, stop and restart, live logs, and plain-English hints when something fails.
- Storage: see your drives, prepare a new drive (it is erased), use an existing one, choose which drive holds movies, music, photos and Nextcloud files, check drive health, and unplug safely.
- Remote access through Tailscale, with no ports opened on your router.
- App updates that save a copy first and put it back if the new version does not start.
- Kit updates from the Settings page, signed and checked, with the old version put back if the new one does not start.
- Server updates and restarts from the Settings page.

## Security

This release includes the fixes from the first security review of the server helper (the "agent"), described in [docs/security-review.md](https://github.com/imtinkering/self-hosting-starting-kit/blob/v0.9.0/docs/security-review.md). The most important:

- Files the server helper writes as root can no longer be redirected by the dashboard to other files on the system.
- A folder on a drive that is a shortcut (symlink) to somewhere else is refused when you choose library folders.
- Drives are mounted so that programs on them cannot gain extra rights on the server.

## Updates from this version

Versions before 1.0 are pre-releases. A server on 0.9.0 is offered newer pre-releases and, later, 1.0. A server on 1.0 or later is only offered full releases.

## Known limits

- No scheduled backups. Only a copy taken just before each app update.
- Immich's machine learning runs on the processor, not the Intel graphics chip.
- Screenshots in the guides are still missing.
- The full list of known limits and planned work is under "Later" in [docs/PROGRESS.md](https://github.com/imtinkering/self-hosting-starting-kit/blob/v0.9.0/docs/PROGRESS.md).

## Check the download yourself

Each release has the tarball, a `.sha256` checksum and a `.sha256.sig` signature of the checksum. The installer and the kit update check them automatically. To check by hand, from a copy of the repository:

```bash
bash scripts/check-release.sh <folder with the three files> 0.9.0
```
